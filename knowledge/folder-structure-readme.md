### Layer Responsibilities & Processing Rules

* **`knowledge/canonical/` (Deterministic Ingestion Target)**
* **Role:** Stores exclusively structured, schema-compliant Excel workbooks and `.cypher` seed files.
* **Pipeline Rule:** Ingested via direct Python + `neo4j` batch loaders without LLM processing.
* **Integrity:** Acts as the immutable baseline schema for your warehouse tables, columns, constraints, and verified SQL templates.


* **`knowledge/raw/` (Enrichment Agent Target)**
* **Role:** Staging ground for unstructured incident notes, shift logs, Confluence exports, and raw text files.
* **Pipeline Rule:** Targeted by the **Knowledge Enrichment Agent**. The agent reads new files from this folder, extracts candidate `(:SOPRunbook)` entities, and validates references against the existing Neo4j tables.


* **`knowledge/staging/` (Human-in-the-Loop Review Buffer)**
* **Role:** Stores candidate JSON/Cypher payloads generated by the Enrichment Agent.
* **Pipeline Rule:** Prevents non-deterministic outputs from writing directly to production Neo4j. The Knowledge Enrichment Studio UI reads this directory so engineers can review, approve, or reject proposed graph additions before merging.


* **`knowledge/archive/` (Processed Audit Log)**
* **Role:** Stores raw files once their contents have been extracted and approved into Neo4j.
* **Pipeline Rule:** Automated ingestion scripts move processed files from `knowledge/raw/` to `knowledge/archive/` with an appended timestamp (e.g., `incident_postmortem_20260827.txt`) to prevent duplicate processing.
